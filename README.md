# 🎵 赞美诗资料智能整理中心（第一版）

面向赞美诗集编辑的本地智能整理系统：**批量导入 → AI 识别整理 → 自动分类去重 → 人工筛选 → 汇总 → 一键导出**。
完全离线可运行，数据保存在本机。

---

## ✨ 功能一览

| 页面 | 功能 |
|---|---|
| 📊 工作台 | 总曲目 / 待审核 / 疑似重复 / 已入选 / 编选进度 / 主题分布 / 最近导入 |
| 📥 曲目收集 | Excel / CSV / PDF / Word / 图片 / 音频 批量导入（拖拽即可）+ 手工新增 + **手机拍照识别自动填表** |
| 🧠 智能整理 | 自动分类（圣经主题 / 崇拜场景 / 音乐类型 / 难度）+ 疑似重复检测 + 人工确认 |
| 📚 曲目库 | 搜索 / 多维筛选 / 排序 / 批量状态流转 / 编辑 |
| ✅ 筛选审核 | 评分 / 评审意见 / 候选 → 初选 → 终选 → 最终出版 → 淘汰 |
| 📤 导出中心 | Excel / Word / PDF / CSV 一键导出 + 《编选报告》全格式生成 |

### 导入支持
- **Excel / CSV**：列名自动识别（`歌名/歌曲名称/title`、`作者/作词/lyricist`、`调子/调性/key`…），不同人的表头都能自动对应；残缺行自动进入“待确认”。
- **PDF / Word**：自动切分曲目（`001 奇异恩典` → 独立曲目），提取歌词与首句。
- **图片 / 拍照**：自动 OCR 识别歌名、歌词、编号（三级引擎：macOS Vision 离线识别 → AI 视觉接口 → 人工补充）。
- **音频**：保存并进入“待确认”，人工补充信息。

### 📱 手机端收集（拍照识别自动填表）
1. Mac 用 `./run.sh --lan` 或双击「启动-局域网.command」启动，手机与 Mac 连同一 WiFi。
2. 手机浏览器打开终端显示的地址（如 `http://192.168.0.237:8787`）。
3. 进入「曲目收集」→ 点 **📷 拍照识别填表**（或拍照上传诗歌）。
4. 拍摄老赞美诗书页 → 系统自动提取**歌名 / 首句 / 歌词**并填入表单，同时保存原图作为附件。
5. 核对修正后点「保存曲目」，AI 自动分类，进入待审核。

### 拍照识别（OCR）三级引擎
- **① macOS Vision（离线，默认）**：调用系统 Vision 框架，中文+英文识别，无需安装任何东西，也无需联网。
- **② AI 视觉接口（可选）**：在 ⚙️ 设置中填入 OpenAI 兼容 API Key 后，本地识别失败时自动改用大模型视觉识别（对书页照片效果最好）。
- **③ 人工补充**：以上均不可用时，照片自动进入“待确认资料”，人工填写。

### 自动分类（本地智能引擎，离线可用）
- 19 个圣经主题、15 个崇拜场景、11 个音乐类型、难度与“会众适唱”星级估算，并给出 AI 置信度。
- 可选接入 OpenAI 兼容接口（⚙️ 设置中填写 API Key），获得真实大模型识别。

### 自动去重
- 歌名 + 歌词双重相似度匹配（含中英混排、繁简、异版歌词），匹配度 ≥ 80% 标记为“疑似重复”。
- 提供 **[合并] / [保留两条] / [不是重复]** 三个人工确认动作。

### 编选流程
`全部曲目 → 候选 → 初选 → 终选 → 最终出版 →（导出）`，淘汰曲目单列。

## 🚀 快速开始（本地）

### 方式一：双击启动（macOS）
1. 双击 `启动.command`（首次运行若被拦截：系统设置 → 隐私与安全性 → 仍要打开）。
2. 自动打开浏览器：<http://127.0.0.1:8787>

### 方式二：命令行
```bash
./run.sh          # 自动选择 Python 运行时并启动
# 或
python3 app.py    # 需已安装依赖：openpyxl pdfplumber python-docx reportlab zhconv pypdf
```
停止服务：终端按 `Ctrl+C`。

> 首次启动自动写入 46 首公有领域圣诗示例数据，并生成示例 Excel / PDF 供体验导入流程。

## 📖 使用建议（第一版工作流）

1. **曲目收集**：把已有 Excel 拖进来；或下载“导入模板”按标准列填写；或拖入《XX赞美诗》PDF 自动切分。
2. **智能整理**：点“一键智能整理” → 系统返回 `✅ 识别成功 X 首 / ⚠️ 需人工确认 / 🔄 疑似重复 / ❌ 资料不完整`；只处理异常即可（无需逐首查看）。
3. **疑似重复**：逐组选择 合并 / 保留两条 / 不是重复。
4. **曲目库**：搜索筛选，批量加入候选库。
5. **筛选审核**：评分（点星）、写评审意见、逐步晋级（候选→初选→终选→最终出版）或淘汰。
6. **导出中心**：选择范围 + 格式 → 生成下载；或一键“编选报告”同时产出 Excel / Word / PDF / CSV。

## 🗂 数据与文件

```
hymn-center/
├── app.py          # 本地服务（零依赖，标准库 HTTP 服务器）
├── engine.py       # 智能分类 + 去重相似度
├── parsers.py      # Excel/CSV/PDF/Word/图片/音频 解析
├── exporters.py    # Excel/CSV/Word/PDF/编选报告 生成
├── seed.py         # 示例数据与示例导入文件
├── static/         # 前端（6 页 SPA）
├── samples/        # 导入模板 + 示例 Excel/PDF（首次启动生成）
└── data/
    ├── db.json     # 曲目数据库（JSON，可备份）
    ├── uploads/    # 上传的原始文件
    └── exports/    # 导出的文件
```

备份 = 复制 `data/` 文件夹。端口可用环境变量修改：`PORT=9000 ./run.sh`。

## ☁️ 部署到 GitHub / 云服务器

本仓库可直接推送 GitHub（建议私有库，数据含版权待核资料）：

```bash
# 1. 推送（需先通过 gh 或 Personal Access Token 认证一次）
./推送脚本.sh
```

部署到云服务器（任意能跑 Python 3.9+ 的主机）：

```bash
pip install openpyxl pdfplumber python-docx reportlab zhconv pypdf
python3 app.py --port 80      # 生产建议加 nginx 反代
```

> 说明：第一版为本地优先架构（JSON 数据库 + 单机服务）。数据量到数万首或需多人协同时，再迁移 SQLite/Postgres + 用户体系。
